# Hardware-Monitoring-System
Hardware Monitoring System is a prototype that provides a centralized dashboard for viewing and managing computer hardware information. It demonstrates the basic workflow of monitoring device status and hardware details in an easy-to-use interface.

# DeviceGuard
A hardware device monitoring system that detects hardware connection, disconnection, enable, and disable events in real time.
